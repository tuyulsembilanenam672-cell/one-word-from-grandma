The single word our grandma would text about AI: **robut**. She means robot, of course — but her thumbs had other plans, and now the machine has a name it never asked for.

## Run it

```sh
node main.ts
```

It writes the one word to `/output/entry.txt` (exactly 5 bytes, no trailing newline).
